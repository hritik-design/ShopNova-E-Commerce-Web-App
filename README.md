📌 Overview

ShopNova is a frontend-based e-commerce web application designed to simulate a modern online shopping experience. It allows users to browse products, search items, apply filters, and manage their cart and wishlist efficiently.

This project is built using HTML, CSS, and JavaScript and demonstrates core frontend development concepts without backend integration.

🚀 Features :

🔍 Product Search with Suggestions
🛍️ Product Listing & Categories
🎯 Filtering (Price, Brand, Rating)
📊 Sorting (Price, Rating, Newest)
❤️ Wishlist Management
🛒 Shopping Cart with Quantity Control
👤 User Authentication (Local Storage)
⚡ Dynamic UI Updates (Real-time)
📱 Fully Responsive Design

🛠️ Technologies Used :

HTML5 – Structure of the web application
CSS3 – Styling, animations, and responsiveness
JavaScript (Vanilla JS) – Functionality and logic
Local Storage – Data persistence (cart, wishlist, user)
DOM Manipulation – Dynamic content rendering

🧠 Key Concepts Implemented :

Event-Driven Programming
DOM Manipulation
State Management
Responsive Web Design
Modular JavaScript Functions
